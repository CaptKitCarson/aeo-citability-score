# AEO Citability Score

WordPress plugin that scores every post on the factors that actually cause AI citation. Not another llms.txt generator (Ahrefs found 97% of those files are unread). This measures what Google AI Overviews, ChatGPT web search, and Perplexity are actually looking at.

**Product page:** https://kitmobley.com/plugins/aeo-citability-score/
